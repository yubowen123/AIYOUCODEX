## 自动恢复写入安装流程

- 登录启动、增强恢复和主题服务显式启用，修复“有启动配置但被系统禁用”的问题。
- 安装器对 launchd 退出/注册冲突有界重试；启动器唤起缺失服务，重复打开保留健康服务。
- 普通原生启动缺少连接参数时，在回复状态确认空闲后内部重开一次；活动或未知任务延后。
- 明确已结束的会话不再被过期 `in_progress` 任务卡误判为正在执行；保持账户数据目录。
