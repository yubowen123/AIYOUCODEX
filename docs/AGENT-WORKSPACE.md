# Agent 工作区：本机迁移与对话接力（页内导航版）

入口：AIYOUcodex 侧栏「Agent 工作区」，通过现有宿主面板与本地桥接运行。结构参考炉子实机：Agent 首页展示“我的 Agent”和“获取更多 Agent”；点击名称进入内容清单，点击“迁移”在原工作区进入单独迁移页，顶部返回按钮回到进入前的页面并恢复滚动位置，首页右上进入上下文接力。迁移记录在首页底部，检测与目录通过每个 Agent 的更多操作进入，不再使用五个平级标签。云端暂不接入，全屏与关闭在面板标题栏右端。

本文件描述实现与验证范围，不代表已在用户环境安装、完成目标软件接手或取得用户验收。

## 检测与适配范围

内置检测 Codex、Claude Code、Hermes、豆包工作、Kimi Work、CodeBuddy、WorkBuddy、Trae Work、OpenCode、Kimi Code、OpenClaw、百度搭子、千问办公、MiniMax Agent、Antigravity、Cursor。

程序检测使用 macOS 系统应用目录、Spotlight 应用索引、PATH 和常见 CLI 目录；内容检测使用各 Agent 的标准目录、别名与手动登记目录。不是从当前项目开始扫描，也不递归读取整盘所有私人文件。程序证据与数据目录分别显示：有内容但程序未检出时标记“本地内容保留”。CLI 只检查文件与执行权限，不执行 CLI。安装证据不代表登录成功。

| Agent | 原生对话读取 | 主要内容映射 |
| --- | --- | --- |

有适配器不代表本机存在记录，也不保证未来版本格式不变。每个 Agent 的检测目录、程序证据和读取问题可在“检测与目录”查看；“手动添加”用于登记其他 Agent 的专用内容目录。共享 Skills 可能被多个兼容 Agent 使用，不能把各 Agent 内容数量相加当成唯一资源总量。百度搭子可识别账户目录，目前写入根目录取发现的第一个账户；迁移前核对实际目标路径。内容清单当前管理 Skills、已识别指令与记忆、会话，不宣称 MCP 连接或插件配置已迁移。

## 按 Agent 分类迁移

1. 在“我的 Agent”点某行“迁移”，确定来源 Agent。
2. 在迁移页的来源/目标区域选择目标 Agent；“带过去”按指令、记忆、Skill、会话分组，可整组勾选，也可展开“逐项”选择。跨分类保留选择，切换来源则清空旧选择。“同时复制到更多 Agent”折叠区可增加目标。
3. 会话只从指定来源 Agent 检索，按标题或项目目录搜索，每页读取100条，可加载更多；整组选择会继续加载至资源上限。详情页可查看用户、助手消息。Skills 迁移整个包，含 SKILL.md、脚本、参考和资源附件。
4. 在折叠区选择同名冲突处理，先“预览迁移”，展开摘要核对逐文件目标路径和动作；服务复核 SHA256，完整校验信息保存在回执。再执行迁移，保存持久回执，支持撤销。
5. 在目标软件确认资源加载结果；复制完成只是文件写入与校验成功。

所有目标均可接收其根目录中的 `aiyou-conversations/<id>/conversation.md` 和 `conversation.json` 可读副本。只保留用户与助手文字，不迁移内部工具调用、附件、认证或可续跑的模型运行状态。

Claude Code 另外支持原生文字会话导入：当源会话有有效的绝对项目目录时，生成 `projects/<Claude 项目键>/<新 UUID>.jsonl`，包含原生消息链、标题与来源元数据，保留原会话。新 UUID 按来源会话签名、来源和目标身份稳定生成；相同来源版本重复迁移不会覆盖该原生文件，来源内容变化则生成新 UUID。原生文件无论选择何种冲突策略，都只允许新建：临时文件通过原子链接创建，既有文件始终保留，避免覆盖 Claude 后续追加的对话。原生导入与可读副本一并纳入事务、校验和撤销。

验证使用本地官方 Claude Agent SDK 0.3.286（对应 Claude Code 2.1.286）的 `listSessions`、`getSessionInfo`、`getSessionMessages`，在隔离目录识别2个项目的原生会话及全部6条文字消息；没有调用模型、启动会话或修改真实用户目录。这证明官方历史读取器可识别生成格式，尚未证明 Claude 桌面会话列表显示或 CLI 恢复执行。缺少有效项目目录时只生成可读副本。其他目标，包括 Codex，当前只生成可读副本，未写入其原生历史数据库，不宣称进入原生会话列表。没有提供原生会话无损复制或运行状态续跑。

指令映射目标文件名，例如 CLAUDE.md → AGENTS.md 或 SOUL.md，内容语义保持原样。另存副本会为整个 Skill 目录或单个指令文件增加副本名称；另存指令须手动合并到默认文件。合并目录只处理来源包含的文件，保留目标额外文件。

## 从实际对话进行上下文接力

1. 接力页默认聚合已适配 Agent 的真实会话元数据，按更新时间排序，每页16条；默认选择最新一段。来源 Agent 的更多操作也可直接进入该 Agent 的会话范围。
2. “换一段会话”折叠区用单选列表切换来源，可加载更多；“找更早的会话”折叠区按 Agent、项目目录及标题搜索。不先要求填入目录或手工录入上下文。
3. 选定会话后展示来源、项目、时间及最后一条文字预览。默认带走最近12条用户与助手消息；“接力内容与提示词”折叠区可调整消息勾选与草稿字段。长对话读取可能截断，界面显示提示，服务返回 `truncated` 标志；展示预览也可能截短文字，生成时使用所选消息的已读取正文。
4. 当前目标和已完成工作分别摘录最近用户输入、助手回复，另有下一步、不确定项和参考路径可核对编辑。这不是模型自动总结，也不能据摘录推断任务已完成。
5. 在“带到哪里继续？”横排目标中选择 Agent。“只复制提示词”生成并复制提示词；“带到目标继续”复制提示词，检测到可打开的 macOS 桌面应用时同时打开它。仅检出 CLI 或没有可打开应用时，提示用户手动打开目标。
6. 在目标会话粘贴并继续，核对目标回复。不会自动创建目标会话、填入输入框、发送消息或执行模型。生成后可展开提示词预览，并选择保存到目标根目录的 `aiyou-handoffs/handoff-*.md`，记录回执。

当前界面默认选择一段会话；“合选同项目会话”折叠区可合选同一来源 Agent、同一项目的1–20条会话，分别默认带走最近12条消息。服务接口校验每条签名与消息归属。来源变化要求重新提取或预览，跨项目集合拒绝接力。保存接力文件沿用回执与撤销。

## 事务与恢复

- 预览有效 15 分钟；复核源内容、目标哈希、Agent 配置及来源对话签名。
- 同一计划重复执行返回既有回执。文件锁序列化本服务写入，无法锁住其他程序的编辑。
- 覆盖先备份，再原子写入与校验；失败逆序恢复，中断回执可重启后撤销。
- 原生 Claude 会话只新建，预览时发现既有文件即跳过；执行期间出现同名文件时原子创建失败并按事务处理，保留另一程序写入的文件，不转为覆盖。
- 撤销只处理哈希仍符合本次结果的文件，保护后续编辑；新增文件删除，覆盖恢复原字节与权限。
- 符号链接、常见凭证文件、私钥、已识别令牌、数据库、.git、node_modules 不直接迁移。原生数据库仅在对话适配器中只读，输出规范化文本。规则排除不能证明任意文件绝不含秘密。
- 最多24个手动 Agent；每批1–12个目标、1–2000项资源、5000个文件、100 MiB；单迁移文件最多8 MiB。一个原生 Claude 会话连同可读副本占3个目标文件，多目标各自计数，大批迁移仍须遵守文件与字节总量限制。JSONL 读取最多64 MiB；所选对话最多保留最近1000条 / 100万字符，截断通过 `truncated` 标志返回。接力草稿每字段最多12000字符，最终接力正文最多4 MiB。
- 回执、计划与备份位于 managedShortcutsPath() 同目录的 agent-workspace 私有目录。保留备份才能撤销；计划可能含接力正文，按本地私人内容保管。
- 原生应用打开目前限 macOS；Windows/Linux 本轮没有实机验证。

## 实现与证据

`lib/agent-discovery.mjs` 管理目录与程序发现；`lib/agent-conversations.mjs` 管理源对话读取；`lib/agent-session-import.mjs` 生成已验证的目标原生格式，不自行写入文件；`lib/agent-workspace.mjs` 管理检索、计划、文件事务与撤销；`inject/agent-workspace.user.js` 提供宿主内统一 UI。生产桥接由 `scripts/injector.mjs` 接入，重连后只重试只读刷新，不重放写入。

验证范围包括隔离真实目录的分类多目标复制、对话筛选与归属、跨 Agent 最近会话分页、只读数据库、冲突/回滚/恢复、源变更拒绝、程序与数据区分、共享目录、Spotlight、生产控件与桥接；原生 Claude 格式另经官方 SDK 读取器核验。浏览器验证使用生产面板与真实服务，但来源为合成夹具，不等同于实际用户目录迁移或原生应用接手。宿主工具禁止自动控制 Codex 自身窗口，最终原生外观与目标应用接手仍需人工读回；Windows/Linux 本轮没有实机验证。

## 页内导航

迁移、来源对话查看、手动添加及撤销预览均在 Agent 工作区原位置切换页面，不使用 dialog 弹层。返回按真实进入路径恢复上一层；Escape 同样返回上一层，不退出整个工作区。首页、内容详情和接力入口共享页面栈。迁移先页内预览，再点击执行；结果进入真实回执，撤销仍须点击明确确认。服务重连/渲染重载不会重放写入；进行中的预览失效，临时操作页返回首页重新选择。
