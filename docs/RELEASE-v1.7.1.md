# AIYOUcodex v1.7.1

设置新增 **关闭插件**：关闭 AIYOUcodex 界面增强并暂停自有工作服务，保留原生 Codex 窗口、草稿、对话与用户配置。原有 **退出 AIYOUcodex** 继续用于退出整个应用。

## 关闭与恢复

打开 AIYOUcodex 设置，在底部点击 **关闭插件**。状态先持久保存，再移除侧栏、主题及扩展面板；刷新、后台恢复和登录启动保持停用。再次手动打开 **AIYOUcodex** 启动器即可恢复。

保存失败时显示错误并允许重试；连续点击合并为一次请求，关闭与退出互斥。停用状态保存在安装目录之外，升级替换程序文件不会清除它。轻量恢复观察器保留，自有工作子进程停止，主题及公告监控暂停。

关闭增强不会卸载已安装的第三方插件，也不改写 GPT 登录、DeepSeek Key 或模型配置。已绑定在宿主进程上的原生模型代理随宿主自然退出结束，本按钮不强行重启 Codex。
