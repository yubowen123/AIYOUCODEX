# AIYOUcodex v1.6.0

v1.6.0 将 Agent 工作区与 OpenChatCut 对话剪辑纳入统一安装包，并整合 10 月 9–11 日的对话、入口和后台恢复改动。源码与本机配置隔离，既有主题安装和下载地址继续可用。

## 新增与修复

- Agent 工作区：发现 16 类本机 Agent，选择 Skills、指令、记忆与真实会话；按项目查看、预览多目标迁移、哈希校验、回执和撤销。Claude 支持原生文本导入，其他目标使用可读副本。凭证检查在迁移计划持久化之前执行；SQLite 与会话头文件的链接来源安全回退。应用启动仅支持 macOS，Windows 使用提示词复制。
- OpenChatCut：按当前 Codex 对话绑定独立工程，右侧显示素材、预览与时间线，隐藏独立 Agent 聊天；包含后台冷启动恢复、原生工具栏整合和提示条关闭修复。轻量原生插件 v1.0.4 随包注册，官方应用 0.2.16 按需安装。已有不兼容 Mac 版本保留并允许安装兼容 managed 副本；Linux 关闭仅针对 exe、启动时间和启动记录均匹配的进程。
- 原生插件：使用安装器实际 Node 可执行文件，写入私有运行副本，解决桌面 PATH 缺少便携 Node 时无法启动的问题；公共插件模板保持跨机器可移植，并保留用户禁用偏好和其他插件配置。
- 对话与入口：快捷菜单长按拖动排序、Alt 调节；生成 NPC 对话按来源过滤，保留同标题的人工会话；项目看板断连自动重建，同时保持任务状态。
- 主题：保留机甲 1.4.3、粉嫩软糖 1.0.4、海边度假 1.2.0、海底假日 1.0.2、YOYO 1.3.2、小新四图轮播 1.0.2。浠浠署名和素材权利说明保留。
- MOKE：2026-10-11 本机只读目录查询成功；此结果不代表所有环境 OAuth 或原生网页入口均通过验收。

## 验证范围

发布前执行整包 Node 测试、项目看板活动回归、公共边界检查、安装脚本语法检查及 macOS/Windows GitHub CI。完整数量和提交以 GitHub Checks 与本次发布记录为准。

Mac arm64 OpenChatCut 的真实素材导入、裁剪、保存、H.264/AAC 导出与重连已有记录；本次回归使用隔离夹具，没有重新生成或发布媒体。Mac x64/Linux 自动安装尚未真机验证；Windows 提供手动安装入口和已有应用检测。新主题原生效果、Agent 目标接手、Windows 实机与整机重启仍待验收。转写、音乐分析与模型生成需要配置相应资源，未在本次发布中验证。
