# Skills 自动与自定义分类

## 使用

1. 点击快捷入口 **Skills 分组**，默认显示 **全部**，覆盖当前工作区、用户目录及插件目录中已发现的 Skill。搜索框按名称和用途检索。
2. 点击分类立即切换：**影视分镜、图像设计、音频音乐、写作研究、办公协作、开发工具**。每个 Skill 只有一个主分类；“常用”仍由星标收藏决定，不是主分类。
3. 点击 **分类管理** 新建分类，也可以改名或删除自定义分类。删除分类只让其中的 Skills 恢复自动归类，不删除或搬动文件。
4. 右键 Skill → **移动分类** → 选择目标。可移动到自动大类或自定义分类，也可 **恢复自动分类**。手动选择优先，刷新目录、再次进入或重启后仍保留。
5. 右键 → **打开所在文件**：macOS 在 Finder 打开所在文件夹并选中该 Skill 的 `SKILL.md`；Windows 在资源管理器执行相同定位。不是进入整个项目工作区，也不是执行 Skill 文件。
6. 右键 **添加到对话** 或点击卡片 `+` 保留原有预填行为，不自动发送。介绍保留两行；悬停卡片可查看准确来源路径，同名但不同来源的 Skill 分别管理。
7. **单击 Skill 卡片**打开介绍弹窗：功能介绍、适用场景、使用方法，以及文件中明确提供的输入要求和交付物。可展开原始说明；关闭按钮、Esc 和遮罩均可关闭，不关闭后面的 Skills 面板。弹窗也支持“添加到对话”和“打开所在文件”。
8. 右键 **追溯 skills**：根据准确文件的成功修改记录，打开最近可验证的优化对话；仅有创建记录时打开创建对话。只阅读、使用、提及 Skill 或失败的修改不算来源，同名 Skill 不混用关联。没有可靠记录时提示未关联，不按名称猜测跳转。

分类过多时分类条可以横向滚动；键盘 Tab 可切换焦点。卡片聚焦后按 Shift+F10 打开操作菜单，方向键选择，Esc 先关闭菜单或分类管理，不直接关闭整个 Skills 面板。

## 自动化与持久化

- 自动分类只使用有界的本地元数据，不调用模型、没有分类请求的 Token 消耗。按明确的技能名称、标题、用途依次匹配；用途未知的条目保留在开发工具及全部中，不隐藏。它是规则归类，不是对 Skill 能力的语义保证，可手动纠正。
- 后端统一决定分类，前端不维护另一套关键词规则；所有条目按准确 `SKILL.md` 路径生成的稳定 ID 分配分类，同名不会串改。
- 配置存放在 AIYOUcodex 用户数据目录下的 `skills/organization.json`，与安装程序分离。多个窗口通过版本检查、文件锁和原子写入避免相互覆盖。
- 文件内容不会因移动分类被改写。Skill 源文件被移动、插件版本目录更换时会形成新身份，不按同名盲目套用原有手动分类；原有记录暂存，可对新条目重新指定。
- 已安装目录按工作区缓存 5 分钟；分类切换和手动调整不触发全盘扫描。刚安装或移动 Skill 后可点 **刷新目录**。目录扫描保留现有深度、数量和耗时上限。
- 打开文件请求只携带准确 Skill ID，由本地目录重新核对文件；不存在或已替换的链接会提示刷新，不能由页面传入任意路径。配置损坏或跨窗口版本冲突不会被静默覆盖。

## 介绍与来源追溯

- 介绍只在点击时读取对应 `SKILL.md`，单次读取最多 64 KiB，内存中最多缓存 32 份；文件发生变化会重新读取。正文、命令示例、HTML、链接都是展示数据，不会执行或访问。未明确写出使用步骤或场景时会如实提示，通用调用方法单独标注，不编造功能。
- 追溯不调用模型。首次需要建立本地历史索引，页面展示进度；关闭 Skills 面板会停止后续追溯请求和自动跳转，再次点击从已保存进度继续。索引建立后只处理追加或发生替换的记录，不因切换工作区重扫整段历史。
- 索引在用户数据目录 `skills/provenance.json` 中，只保留文件路径、对话标识、修改时间、修改类型与读取位置，不复制聊天正文或补丁内容，不进入公开仓库。
- 可验证来源包括原生成功补丁回执，以及 `apply_patch` 调用与对应成功结果（含已支持的单次、无条件 `functions.exec` 包装）。任意 shell / Python 脚本、外部安装或编辑不能仅凭一段命令推断为成功写入；没有这些证据的历史无法保证完整追溯。归档后不在本地活动记录目录中的对话不会猜测跳转；过长或不可读的历史会标注追溯范围受限。
- 优先级依据真实成功修改时间，而非最近聊天时间。新增 Skill 的辅助文件也算优化；迟到响应在弹窗关闭、切换 Skill 或关闭面板后不会重新打开弹窗或导航。

本页分类配置与输出偏好中的“默认 Skills”互相独立，不会因移动分类更改自动使用的技能，也不会自动运行技能。
