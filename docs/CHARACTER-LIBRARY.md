# 角色资产库

资产控制台顶部可切换紧凑缩略图与详情视图，侧边分类保留项目内筛选。双击文本、图片、音频、视频仍是预览详情；添加到对话是独立操作，不自动发送。

## 角色与衍生关系

- 使用角色名称、目录与文件名线索、生成提示词和本机参考素材记录建立项目内角色分组。
- 已知同角色的基准图、状态图及不同样式图相邻排列；先分组排序，再分页，不仅整理当前页。
- 图片角色角标打开关联编辑：设置名称、状态、样式与来源基准图，查看同组素材；确认后保存。
- 同名角色不跨项目合并；不同角色、含糊多参考与匿名图片不强制归组；循环来源链有界处理。
- 人工修改优先；可排除错误关联，后续自动整理不覆盖人工排除。只修改本地索引，不改名、搬动或删除原文件。

## 相似候选的边界

“本地找相似”只按需比较当前已加载的图片缩略图（最多 120 张），按构图与颜色提供最多 12 个候选。不上传图片，不调用视觉模型，不做人脸身份认证，不后台全库扫描；画面相似不代表同一个角色，候选需人工确认。

确认关联后可筛选同角色图片；清除角色筛选恢复原列表。编辑使用版本检查，过期保存失败不会覆盖新数据。

## 验证

规则与 API 回归：`test/character-associations.test.mjs`、`test/character-library.integration.test.mjs`。本机只读 UI 检查入口：`node scripts/verify-character-library.mjs /absolute/output/directory`；该探针不自动保存角色关系。
