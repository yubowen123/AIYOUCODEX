# 对话专属文件夹

每条本地对话按稳定的 thread ID 绑定一个输出目录，默认结构如下：

```text
所属项目工作区/
  生成角色设定图/
    .aiyoucodex-thread.json
    角色图.png
    提示词.md
  整理视频报告/
    报告.md
```

## 创建与保存

- 原生 `SessionStart` / `UserPromptSubmit` 钩子在模型执行前建立目录并提供绝对输出路径。未取得正式标题时先用“新对话-ID”；正式标题可用后同步。
- 后台增强服务补充处理新建/最近使用的对话；历史对话在再次打开或使用时建立目录，不批量搬迁历史文件。
- 新建文本、图片、音频、视频和报告默认保存到对话目录。模型需显式设置输出路径，工具返回缓存文件时复制本轮产出再交付。
- 这是模型可见的默认保存规则，不是操作系统强制隔离，也不会改写任意 shell 命令、修改原生 cwd、重写历史会话数据库。用户明确指定的位置优先，已有项目代码原位修改。
- 只读/不可用工作区、远端路径、缺失目录和损坏映射会明确报错，不默默退回整个项目目录。普通对话不因此被阻断；目录规则不可用时不能宣称自动归档成功。

## 名称同步与持久性

- 文件夹名随对话名同步。跨平台不允许的字符替换成下划线，过长名称截短；同名冲突追加对话 ID 短后缀，绝不合并两个对话。
- 原生标题索引是命名来源，不从提示词、工具输出或同名卡片猜测绑定。
- 运行中改名先标记待同步；读到原生完成/中断状态，或下一轮开始前再同步，避免改变正在写入的绝对路径。未知状态保守等待。
- 目录原地改名，内容保留。目录中的隐藏绑定标记与本地数据目录中的写入意图共同用于重启恢复。
- 文件夹被人工移动、删除或替换时不创建空目录冒充原数据。工作区真实路径改变时不自动跨盘搬家，需要先解决绑定。
- 更新程序不会清空目录映射。卸载程序也不应删除用户的对话产出目录。

## 打开文件

在对话右上角点击 **打开文件**：

- **打开母文件夹**：打开所属项目工作区，选中本对话的同名目录。
- **打开子文件夹**：直接进入该目录。

菜单展示真实路径；对话切换或改名导致路径变化后，旧菜单请求失效，需要重新打开，避免选错目录。

## 安装与原生钩子

macOS / Windows 安装脚本合并已有的 `AIYOUCODEX: bounded output preferences` 会话钩子，保留其他钩子并备份配置。新处理器仍需在原生 Codex `/hooks` 审阅并信任；安装器不修改信任数据库。已有相同处理器无需重复写入配置。

手工配置：

```sh
node scripts/setup-efficiency-hooks.mjs --apply
```

钩子独立于“输出偏好”开关：关闭简洁输出并不会关闭目录规则。每次发送消息提供当前目录，合并后的上下文限制为 4096 字符。没有真实钩子事件回执时，只能确认目录已建立，不能确认模型已收到保存规则。

目录映射默认位于 AIYOUCODEX 用户数据目录 `efficiency/conversation-folders/directories.json`。测试可用 `AIYOUCODEX_EFFICIENCY_DIR` 隔离。后台仅读取轻量标题索引、目录元数据及有界的会话状态尾部，不递归扫描图片/视频内容。

机制依据：[OpenAI 原生 Hooks 文档](https://learn.chatgpt.com/docs/hooks)。当前实现使用启动/提交前上下文，不使用 `PermissionRequest` 自动批准，不把目录规则当作额外执行授权。
