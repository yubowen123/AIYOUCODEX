# AIYOUcodex v1.7.0

本版将 DeepSeek 模型接入、Skills 与资产搜索、各模块加载改进纳入统一发行包，并包含海岛心动陪伴 v1.0.2。此前 v1.6.0 的 Agent 工作区、OpenChatCut 对话工程和主题专区继续保留。

## 新增与修复

- **GPT 与 DeepSeek 共存**：macOS 原生模型菜单追加 DeepSeek V4.1 Flash，同一对话可双向切换；GPT 默认模型、登录与历史保留。设置页保存独立 Key，只返回配置状态，不回显秘密值。随包分发模型目录和 Node.js 认证 helper，新安装无需个人机器的 Python 脚本。配置仅应用到子进程，不改写全局 `config.toml` 或 `auth.json`。已有显式 provider/profile 配置继续优先。长上下文返回 GPT 时使用准确的目标模型窗口，阻止不完整窗口信息导致的错误切换。[使用步骤与限制](DEEPSEEK.md)
- **Skills 与资产搜索**：增加 Laya / 普通搜索切换，Skills 搜索结果按精确 ID 引用；资产按名称、标签和已有资料文本查找，显示命中摘要。搜索、翻页时保留已显示卡片，读取失败允许重试，Laya 不可用时回退普通搜索。没有新增图片、人脸或音视频内容识别。
- **加载与恢复**：Agent、Claude、OpenChatCut、模型竞技场、任务看板显示实际加载状态，支持慢连接提示与失败重试，避免过期回执覆盖新状态。保留已加载内容、未发送草稿和已保存剪辑工程；剪辑器区分“界面已打开”和“工程已就绪”，安装进度按实际百分比显示。
- **项目入口**：保留顶部随所选项目变化的新建对话入口，移除搜索行重复的新建对话及项目选项按钮；创建项目与排序保持独立。
- **运行时**：设置增加明确退出入口，退出后不被后台立即重新拉起；大体积渲染脚本按块传送与注册，降低加载失败，挂载失败可清理本次注册。
- **主题**：海岛心动陪伴 v1.0.2 使用连续视频，声音默认关闭，可在主题设置打开。沿用现有主题专区、独立下载和社区署名。该视频保留当前用户选择的版本，循环接缝仍有轻微局部姿态差异，不宣称完全无抖动。

## 安装与升级

从 [v1.7.0 Releases](https://github.com/yubowen123/AIYOUCODEX/releases/tag/v1.7.0) 下载源码安装包，按主 [README](../README.md) 的 macOS / Windows 步骤安装。发行附件不是预装大型剪辑应用的离线整包。已有主题配置和登录继续保留。

使用 DeepSeek：结束当前生成后完整退出客户端，从更新后的 **AIYOUcodex** 入口重开，在设置中配置自己的 DeepSeek API Key，再从原生模型菜单选择。**本版自动 DeepSeek 接入仅限 macOS**；Windows 包含其余搜索和界面改进，尚未启用原生模型代理。仅热更新页面不足以替换旧进程的模型代理。

## 验证范围

新增功能经过隔离测试：DeepSeek 菜单共存与双向切换、压缩窗口、认证设置、空配置目录加载、搜索与分页、模块超时重试、草稿保留和剪辑工程恢复。发布包代理连接原生 CLI `0.162.0-alpha.17.2`，在空配置目录成功创建 DeepSeek 临时对话，未提交付费模型回答，未创建全局配置与登录文件。

前期 macOS 原生 CLI 的 GPT → DeepSeek → 主动压缩 → DeepSeek → GPT 真实请求与合成标记验证已有记录。本次发布回归使用隔离浏览器和本地模拟服务，不读取私人对话或密钥，不新增视频生成。完整测试数量和 macOS / Windows CI 以本次 PR 的 Checks 为准。

桌面完整冷启动、Windows 原生 DeepSeek 请求、实际用户历史和新主题原生效果仍待实机确认。隔离测试与 CI 通过不等同于这些实机验收；Laya 真实语料的检索质量也未在本次回归评估。
