# 海边度假 · 浠浠 v1.2.0

设计署名：浠浠。保留 v1.0.0 七位度假角色、海浪、棕榈叶及小螃蟹素材。

## 卡片配置（1.2.0）

当前 AIYOUcodex 共用主题控件支持动态 / 静态卡片颜色、背景色、边框色、0–8px 边框粗细及流光颜色。动态分别配置执行中、已完成、执行中断、待执行 / 空闲，静态统一样式。背景沿用卡片透明度，边框与流光沿用边框透明度。保存 / 取消与其他主题设置一致。旧版 AIYOUcodex 可正常运行主题，但需更新共用主题逻辑才能显示这些新控件。

## 本版优化

- 界面由柠檬黄 / 橄榄文字改为奶油沙色、晚霞粉、深海蓝；侧栏、气泡、输入、菜单、资产、竞技场、看板和设置使用同一语义色卡。
- 收发气泡统一 12px × 14px 内边距、16px 圆角、1px 边框和软阴影；保留原生对齐与阅读列宽。Claude 内部 Markdown 不重复包壳，空回复不显示空框。
- 内置视频为环境循环，不再借用“运行中”事件；选择静态图、关闭动效、窗口不可见或系统减少动态时回退同一海滩场景图。
- 删除已隐藏但仍创建的重复美人鱼 DOM 与旧动画；修正旧模板说明和标签。
- 输入框与输入区外层仍独立调节透明度。沿用 `beach-vacation` 身份和 `aiyoucodex.theme.beach-vacation.v1`，保留升级前个人设置。

## 安装

需要已安装 AIYOUcodex 与 Node.js >=22.5；本包是主题包，不是完整应用安装包。

macOS：`./install.command /AIYOUcodex目录`；不传参数时使用标准已安装运行时目录。

Windows：`./install.ps1 -AIYOURoot "AIYOUcodex目录"`。

通用方式：在 AIYOUcodex 仓库运行 `node scripts/install-theme.mjs --package /主题解压目录 --dry-run`，检查通过后去掉 `--dry-run` 安装。进入「主题与动效」选择「海边度假·浠浠」并保存。

升级保留既有颜色偏好；若要使用本版默认色卡，在主题面板点「恢复默认」，确认预览后保存。取消会恢复先前设置；系统默认通过原主题目录回退。
