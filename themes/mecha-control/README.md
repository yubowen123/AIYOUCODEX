# 机甲控制舱

独立主题包，需要 AIYOUcodex v1.5.1 或更新版本。

macOS：`./install.command /AIYOUcodex目录`。Windows：`./install.ps1 -AIYOURoot "AIYOUcodex目录"`。通用：在源码仓库运行 `node scripts/install-theme.mjs --package /解压主题目录 --install-dir /已安装运行时目录`。先加 `--dry-run` 可仅校验。安装后在主题与动效中选择并保存。

支持动态 / 静态卡片颜色、边框粗细与流光，以及独立透明度。当前预览截图见仓库 README；个人设置独立保存。代码 MIT，素材说明沿用主题上游。
